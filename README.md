# 오늘 한 수 · badook

완전 초보자를 위한 한국어 바둑 교육 앱입니다.

- 원목 바둑판과 입체 바둑알
- 30개 수업, 120개 학습 활동, 용어사전과 힌트
- 9줄 연습 대국, 수동 계가와 복기
- 브라우저 로컬 진도 저장 및 JSON 백업

## 실행

빌드와 API 키 없이 `dist/`를 정적 웹 서버로 제공합니다.

```sh
python3 -m http.server 8000 --directory dist
```

http://localhost:8000 접속. 파일을 직접 여는 file:// 방식은 ES 모듈 때문에 지원하지 않습니다.

## 검사

```sh
npm test
```

Node.js 내장 테스트 러너를 사용합니다. 외부 의존성이 없습니다.

## 배포

정적 호스팅의 출력 디렉터리를 `dist`로 지정합니다. 별도 빌드 명령은 필요하지 않습니다.

## 현재 제한

- 연습 상대는 간단한 규칙 기반 프로그램입니다.
- 사활과 공배는 사용자가 확인하여 계가합니다.
- 기록은 현재 브라우저에 저장됩니다.
- 음성 안내는 브라우저 읽기 기능입니다. ElevenLabs 효과음은 아직 추가되지 않았습니다.
- 실제 브라우저 화면 및 터치 검증은 아직 완료하지 않았습니다.
